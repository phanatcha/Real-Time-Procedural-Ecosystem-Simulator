# Recording simulation runs

Add **Simulation Run Recorder** to the scene's **Species Manager** object using Add Component, before pressing Play. Recording is opt-in; the main scene does not acquire the component automatically. Set `Experiment` to the treatment/run label. In the Editor, leaving `Source Revision` as `unrecorded` automatically records the full Git commit plus `+dirty` when the checkout has changes. An explicit revision is preserved (the soak runner supplies one for its copy). Player builds still need an explicit revision; absent Git or a provider, the value remains `unrecorded`.

The Console prints the output directory: `Application.persistentDataPath/SimulationRuns/<UTC timestamp>-<unique ID>`. Each regenerated world opens a fresh directory. Disabling the component or leaving Play closes the files and captures the final state when possible. No run, including an extinction, is deleted. Abrupt termination may leave no `ended.txt`; the CSV files flush after every sample.

Files:

- `metadata.json`: schema version, UTC start, world seed, revision label, experiment, Unity version, interval, off-screen flag, and serialized starting settings for the manager, season clock, food spawner and one representative animal. If no representative exists yet, its settings are empty. This is an audit snapshot, not a replay/save format; Unity object references do not contain referenced asset contents.
- `population.csv` (schema 3): cumulative births split into cloned/sexual, deaths by cause (including `thirst` since 1 November 2026), live/off-screen counts, living species, population-ceiling flags, requested/achieved speed, season, effective strength and off-screen flag, followed by cumulative `breeding_wait_episodes` and `breeding_wait_seconds`.
- `species.csv`: persistent species IDs/names, parent, origin/extinction, current counts and cumulative birth/death counters. Extinct species continue to appear. The two breeding-wait counters are also saved per species.
- `traits.csv`: each inherited gene (including `LitterSize` since 1 November 2026), harmful mutation count and perk indicator, with live sample count, mean, population standard deviation, min and max. Perk means are their population shares. Traits are sampled directly from live genomes, not seasonally adjusted movement/temperature values. Empty populations have blank statistics; previous observations remain in the file. Off-screen genomes are excluded and sample counts make this explicit.
- `events.csv`: outside interventions, with the simulated time of each: god tools (a drought, dropped food, a mass extinction, a burst of mutation and their ends; see `GodTools`), as the Species Manager records them. Empty in a run nobody interfered with.
- `ended.txt`: normal closure reason. Missing means completion was not confirmed.

The default cadence is 10 simulated seconds. Pausing does not add duplicate samples; higher speed changes wall-clock duration, not the sampling clock. Sampling occurs on the first frame reaching each boundary. If a long frame crosses multiple boundaries, the recorder writes one current observation with its actual time; it cannot recover unobserved history. Finalization may add a partial-interval observation. Do not assume perfectly equally spaced rows when graphing.

Use constant settings during evidence runs. Metadata captures initial settings, not a full intervention history. Keep **Keep Distant Animals As Numbers** off: that model does not include mating, mutation or individual selection. Record all replicates and extinctions.

A breeding-wait episode begins when a mature, sufficiently fed animal with no reproduction cooldown is held back by its applicable land/sea population ceiling. A mate-seeker uses its existing minimum partner-energy threshold. Continuous waiting counts once, irrespective of frame rate. Wait seconds sum simulated time across waiting animals (animal-seconds), not wall-clock time. Losing eligibility or leaving the ceiling ends an episode. Pauses add nothing; world regeneration resets totals. These measure the existing breeding gate, not fertility failures or unreachable mates.
